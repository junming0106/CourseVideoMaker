# 版面與手繪風格

畫面怎麼排、字卡怎麼用、等待怎麼顯示、背景音樂怎麼選。
從 2A1（會走路的雪人）實作後收斂出來，**每一條都是使用者回報過的問題**，不是設計偏好。
實作在 [`tools/lib/sketch.mjs`](../../../../tools/lib/sketch.mjs)，範例看 `lessons/_reference-2A1/`。

---

## 一、版面：三層，全部在綠色黑板內

使用者的原話：「所有元素都在黑板位置，不要超出綠色版面的範圍」「字卡或圖片出現後，不需要的請清除，
要保留的就規劃自身大小與擺放位置，避免與其他元素重疊」。

綠板實際範圍約 x 240~1685、y 199~900（用渲染出來的畫面量的，不要看 SVG）；可用範圍再各縮 30~40px：

| 層 | y 範圍 | 放什麼 |
|---|---|---|
| **標題帶** | 218~326 | 一次只出現**一張**字卡，後出現的取代先出現的 |
| **內容區** | 344~736 | 截圖、積木、示意圖，最大高度 392 |
| **字幕帶** | 752~880 | 對話框，固定在黑板下緣，尖角朝說話的角色 |

- 字卡（`md`）實際高度約 100px，不是 70。標題帶要留到 y 326，內容從 344 起，不然字卡會壓到圖的上緣（2A1 踩過）。
- **對話框不要放在黑板外面**。2A5 的對話框在板子兩側、角色頭上，使用者回報「對話框的角圖層有問題」（尖角被角色的頭蓋住）
  和「元素超出黑板」。改成黑板下緣的字幕帶之後，兩個問題一起消失。
- 對話框獨立成一層，DOM 順序排在**角色 clip 之後**（角色要在全屏段落之後、對話框要在角色之後）。
- 安全區：角色在左下／右下角（x < 450、x > 1470），字幕帶 x 470~1450，內容區 x 280~1640。
- 章節卡可以整片換成橘色斜紋底（讓學生知道換單元），它不算「元素超出黑板」。**其他段落一律同一塊黑板**，
  包含開場、成品、片尾——不要為了「情境」換成沒有黑板的黃底。

### 規劃與清除

- **每個出現的東西都要想好怎麼離開**：標題字卡用 `titles()`（下一張出現時自動 `fadeOut` 上一張）；
  圖片用完要 `autoAlpha:0`（例如 `openPaint` 開畫布時收掉前一張）；要留的先排好固定位置。
- 用 `fit()` 算圖片矩形、用 `place()` 放，**不要用「左邊 640px」這種憑感覺的數字**。
- 同一個位置先後放兩樣東西，要在 build 裡確認前一個已經淡出。
- 抽樣時看**縮圖找「壓到」**：兩個東西邊緣相碰、字卡蓋住圖片上緣、小圖壓到積木，縮圖上一眼就看得出。

## 二、手繪風格

使用者要的是「跟教室一樣的手繪風」：米色紙面、咖啡色粗線條、邊緣歪歪的。

**做法：外框用 SVG 濾鏡畫歪，文字留在濾鏡外面。**

```css
.sketch { position: relative; isolation: isolate; }          /* isolation 讓 z-index:-1 的外框停在卡片裡 */
.sketch::before { content:""; position:absolute; inset:0; z-index:-1;
  background: var(--bg); border: 5px solid #4A2E14; border-radius: 26px 34px 24px 32px / 32px 24px 34px 26px;
  box-shadow: 5px 6px 0 rgba(74,46,20,.30); filter: url(#rough); }
```

- ✗ 整個元素套 `filter`：字也會被扭歪，小字讀不出來。✓ 只套在 `::before` 外框上。
- 外框用不規則的 `border-radius`（四個角不一樣）再加位移濾鏡（`feTurbulence` + `feDisplacementMap`，scale 4~5）。
- 圈選／箭頭用更大幅度的濾鏡（`rough2`，scale 11），並改成紅色麥克筆的顏色（`#E8533F`）。
  使用者說「打圈的也要用手繪風格」——正圓像 UI 元件，歪的圈才像老師拿筆畫的。
- 全片只有兩種線條色：咖啡色 `#4A2E14`（外框、文字）、紅色 `#E8533F`（引導）。紙面 `#FFF8E6`。
- 字型仍然是圓體／黑體、字重 800 以上（見 teaching-rhythm.md 一之三），手繪感來自外框，不是來自手寫字型。

## 三、字卡與動畫：收斂

使用者的原話：「畫面太凌亂，字卡不需要這麼多種類」。2A5 有 12 種卡片外形、6 種顏色、15 種進場動畫，
看起來像一堆貼紙。

| 項目 | 規則 |
|---|---|
| 外形 | **只有一種**手繪紙卡（`.sketch` / `.note` / 共用 `card()`）。小標籤、徽章、選項卡、工具卡全部用同一種，只換內容 |
| 顏色 | **3 種**：橘＝重點、藍＝提示／補充、綠＝正確／完成。紅、黃、紫一律映射掉（`TONE_MAP`） |
| 大小 | `sm` 34px、`md` 46px、`lg` 64px。沒有 `xl`（最大 `lg`） |
| 進場動畫 | **`pop`**（字卡）、**`rise`**（圖片）、**`stamp`**（答對、章名）。其他名稱一律當 `pop`（`FX_ALLOWED`） |
| 關鍵字 | `hi()` 一句只標一個；顏色改成深橘 `#D9480F`（黃色在米色紙面上看不見） |

在 build 裡呼叫 `makeSketchKit(hit)` 取得收斂過的 `fx` / `card`，不要直接用 `makeFx` / `makeCard`。

## 四、等待：只有「需要想」的地方才停，而且停得看得見

### 什麼時候停

使用者的原話：「問問題的地方可以直接交給夥伴回答，比較重大的問題，像是確認是不是學會程式觀念、問考題等才要等待時間」，
以及「角色問自己夥伴的話也變得會停頓」。

| 要停（`hold`） | 不要停（交給夥伴回答） |
|---|---|
| 練習題、複習題（A/B 選項、「這塊積木做什麼」） | 「你猜哪一區是舞台？」之類一問一答就好的小問題 |
| 「猜猜看」的變化題（先猜再驗證） | 反問句（「想不想做一隻？」「你覺得要全部學完嗎？」） |
| 回扣開場的問題（驗收這堂課學會沒） | 看示範的停頓（「看，彈回來了！」） |
| **必須動手**：跟著操作（「你也打開了嗎？」）、抄程式（「暫停影片照著排」） | 沒有標準答案的問題（「你最想畫什麼？」） |

判斷方式：**問題的答案如果要靠螢幕前的學生自己想／自己做，才停；如果夥伴一句話就能回答，就不要停。**
停頓不是越多越好——2A1 第一版 52 處停頓，使用者看了覺得拖，最後只留 22 處（約 103 秒）。

### 怎麼顯示

使用者的原話：「等待時間應該可以水平垂直置中，然後顯示一個手繪風格時鐘＋秒數」。

- **黑板正中央**一個手繪鬧鐘（兩個鈴鐺、兩隻腳、12 根刻度、紅色秒針每秒轉一圈），數字在鐘面正中央。
  `clockHtml()` + `clockTimelineJS()`。
- **有停頓的畫面，中間 x 860~1060、y 475~665 一定要留空。** 練習題的 A、B 選項分左右兩邊、鬧鐘在中間；
  複習題積木放上方、答案放下方；抄程式的畫面把程式靠左、右邊放成果。**先排版再放鐘，不要鐘出現了才發現蓋住題目。**
- **數字不要用 `fx.mjs` 的 `countdown`（innerText 補間）。** 渲染是逐格「跳著抓」畫面，innerText 補間在跳著抓時
  會顯示成 `0`，鐘剛出現的 0.4 秒也會顯示 `0`。改成「每個數字一個元素、到時間才 `autoAlpha:1`、下一秒 `autoAlpha:0`」，
  不管怎麼抓都對（2A1 實測踩到，`clockTimelineJS` 已修）。
- 秒數上限 5。`hold` 超過 5 的（抄程式 6 秒）鐘只倒數 5 秒，剩下當作緩衝。

## 五、引導（圈選與箭頭）

- 一次只能有**一個**（`guides()` 讓前一個在後一個出現前離場）。
- 座標是**圖上的百分比**，用 5% 網格疊圖量出來，**不要目測**。裁切過的圖要用 `cropPlace().map()` 換算，
  不然裁切之後整組座標都歪。
- 圈要比目標大一圈（`pad`），不然壓在字上。
- 兩個引導講在**同一句台詞**裡（例如「按 File，再按 Save as」）要錯開時間（`off: 0.35` 與 `off: 1.6`）。

## 六、截圖處理

- **要裁到該步驟真正要看的區域再放大**（`cropPlace`）。整張編輯器截圖塞進內容區，字只剩 10px 看不見。
- **遮蓋真實個資**：教案截圖的左上角常有真實學生姓名與頭像（2A1 的遊樂場首頁就有）。
  `prep-assets.py` 用側欄底色整塊蓋掉，並用 `.masked` 旗標檔避免重複處理。登入畫面（有帳號）一律不放，從登入後開始。
- **去背不能只靠 Pillow `floodfill`**：它在細線條的圖上會把背景從線條斷點漏進去，肚子、頭整個挖成透明
  （「雪人肚子顏色不見了」）。做法：先把「墨線」膨脹 3 圈封住斷點，再從邊界填滿，最後把多封的 3 圈往回長。
  背景若有網格線或點點（顏色接近背景），不能用「接近白色」判斷，要用「不是墨線」（亮度低或藍色通道低）。
- **貓咪這種單一角色圖要裁到內容邊界**（門檻比外框細線更暗，`< 170`），不然白底卡片裡只剩一個小點。
- 錄影（`media*.mp4`）：先逐秒抽格看過內容再決定取用區間（`CLIPS`），旁白步驟順序要跟錄影裡實際操作順序一致
  （2A1 的帽子是「先改黃色、再用塑型拉尖」，不是反過來）。再用 `mk-clips.mjs` 變速到剛好撐滿段落，並靜音。

## 七、背景音樂

使用者的原話：「背景音樂太讓人想睡覺了，有沒有比較像巧虎卡通悠閑輕快的音效」。

- ✗ 慢板（60~80 BPM）、單音琶音、長衰減、大混響、音樂盒音色——低年級聽了想睡。
- ✓ **116 BPM、直拍**、木琴旋律（短促、泛音亮，音域 G5~D6）、**彈跳低音（第 1、3 拍）＋烏克麗麗式反拍和弦**、
  沙鈴每個八分音符、木魚落在 2、4 拍；和弦用 C–G–Am–F 這類大調明亮進行；回音要短（55ms），不要拖尾。
- `tools/produce/mk-bgm.py` 純合成、不用外部素材，`run-pipeline` 缺音樂或音樂比片短時自動跑。
- 音量由 `mk-audio-bed.py` 依 RMS 正規化，播出後約 -30 dB，墊在人聲（約 -17 dB）下面。
  **預聽檔要拉大音量（+10 dB）再給使用者**，否則他聽不到而以為沒做好。

## 八、檢查流程（渲染前一定要做）

1. `lint` 0 error。
2. **每一段都抽中點畫面看過**：`snapshot` 分批（每批 9 張）、合成 3×3 拼貼圖、逐張看。
   `snapshot` 沒有逾時參數，要用環境變數：
   `PRODUCER_PAGE_NAVIGATION_TIMEOUT_MS=180000 PRODUCER_PLAYER_READY_TIMEOUT_MS=180000 npx hyperframes snapshot . --at t1,t2,...`
   （第一次不加會報 `Navigation timeout of 10000 ms exceeded`）。
3. 找「壓到」「超出黑板」「圖片沒收」「字卡太寬」「倒數圈壓到內容」這幾類，縮圖就看得出。
4. **給使用者看之前，先渲染 3 分鐘的短預覽**（`UNTIL_SEG=<段落id> node build-composition.mjs`），
   不要一次渲染整支（25 分鐘的片在這台機器要一個多小時）。短預覽要包含：開場、一張截圖、一題練習題（有鬧鐘）、一次圈選。
5. 預聽音樂、預覽影片都**確認檔案存在且規格對**（`ffprobe`）再傳；傳之前先自己確認音量不是太小。
6. 不要 `sleep` 等渲染——用 `run_in_background`，完成會通知；要看進度就看 `captured-frames` 的張數。
