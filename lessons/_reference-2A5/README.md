# 參考範例：2A5 貓抓老鼠

一支做完的課（23 分 57 秒，1~3 年級），留在這裡當**寫新課的對照**。

**這門課不能直接跑**——素材（操作截圖、程式碼圖、語音、音樂床）沒有一起帶進包裡，
只留下講稿與版面的原始碼。

## 打開來看什麼

| 檔案 | 看什麼 |
|---|---|
| `script-data.mjs` | 講稿怎麼寫：段落切分、`who`／`action`／`text`／`hold` 四件事怎麼一起決定、章節卡怎麼下 |
| `build-composition.mjs` | 版面怎麼組：對話框、程式碼展示、紅框、倒數計時、章節卡的實作 |
| `course.json` | 一門課要設定哪些路徑與參數 |
| `grade1-3.md` | 產出的可讀講稿長什麼樣（含每句實際秒數） |
| `sfx-cues.json` | 音效時間點的格式 |

## 寫新課時

複製 `build-composition.mjs` 過去改，**不要複製 `tools/` 的共用腳本**——
2A4 就是複製了一份，結果修好的 bug 沒回流到 2A5。
